# Security service comparisons

| Requirement | Starting point | Evidence or control |
| --- | --- | --- |
| Identify supported suspicious activity | GuardDuty | Threat findings |
| Assess supported vulnerabilities | Inspector | Package and exposure findings |
| Find supported sensitive data in S3 | Macie | Sensitive data discovery findings |
| Record account API activity | CloudTrail | API and other supported events |
| Assess resource configuration | AWS Config | Configuration history and rule evaluations |
| Inspect supported HTTP requests | WAF | Request filtering and rule telemetry |
