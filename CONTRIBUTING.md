# Contributing

Open an issue or pull request with the certification, task number, technical claim and official AWS reference. Explain the workload assumptions behind architectural choices and distinguish current service behaviour from legacy configurations.

For labs, document prerequisites, permissions, expected results, charges and cleanup. Use fictitious resources and omit credentials, account details and screenshots you cannot license. Write original practice scenarios and explanations. Review the [code of conduct](CODE_OF_CONDUCT.md) before participating.
