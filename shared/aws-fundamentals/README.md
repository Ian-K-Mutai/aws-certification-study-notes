# AWS architecture fundamentals

A Region is a geographic boundary containing multiple Availability Zones. An Availability Zone is a failure-isolation boundary within a Region. Confirm the scope of each service and its dependencies before assuming that a multi-AZ design survives a regional outage.

Evaluate designs against the six Well-Architected pillars: operational excellence, security, reliability, performance efficiency, cost optimisation and sustainability. A trade-off should name the requirement it satisfies and the cost, risk or operational work it introduces.

[Well-Architected Framework](https://docs.aws.amazon.com/wellarchitected/latest/userguide/waf.html)
