# Shared responsibility

AWS operates the underlying cloud infrastructure. The customer remains responsible for how their workloads, identities and data are configured. The division varies by service. With EC2 the customer administers the guest operating system. With managed data services AWS takes on more infrastructure operation, while the customer still decides which principals can access the data and how application security is enforced.

For each workload, assign ownership for patching, credentials, data protection, logging, backup testing and incident decisions. Assess responsibility at component level because one architecture can combine many service models.

[AWS shared responsibility model](https://aws.amazon.com/compliance/shared-responsibility-model/)
