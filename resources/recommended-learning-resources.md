# Recommended learning resources

- Read the applicable exam guide and use the domain task lists to select notes and identify areas for practice. [Official AWS exam guides](https://docs.aws.amazon.com/aws-certification/latest/examguides/)
- Use the Well-Architected pillars to review a design and explain the trade-offs between its security, reliability, performance and cost. [AWS Well-Architected Framework](https://docs.aws.amazon.com/wellarchitected/latest/userguide/waf.html)
