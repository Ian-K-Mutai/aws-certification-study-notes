# Glossary

| Term | Definition |
| --- | --- |
| Availability Zone | A failure-isolation boundary within an AWS Region |
| RTO | Maximum acceptable time to restore a service after disruption |
| RPO | Maximum acceptable period of data loss |
| SCP | Policy that limits permissions available in an AWS Organizations member account |
| IOPS | Input/output operations per second |
| OAC | CloudFront origin access control for authenticating requests to a supported origin |
| DLQ | Dead-letter queue for messages removed from normal processing after repeated failure |
